# Hu1zMinimal - Unity 2022 WebGL 模板

适配博客 iframe 嵌入，canvas 自适应 + 点击坐标对齐。

## 使用

1. 把整个 Hu1zMinimal 文件夹放到 Unity 项目的 Assets/WebGLTemplates/
2. Player Settings → Resolution and Presentation → WebGL Template → 选 Hu1zMinimal
3. Build

## 导出后检查

如果导出后 loader 的 script src 为空，需要手动改成实际文件名，比如：
<script src="Build/你的游戏名.loader.js"></script>
